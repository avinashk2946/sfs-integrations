Platform & architecture

Built on a resilient cloud foundation

Smart Food Safe is a multi-tenant SaaS platform hosted on Amazon Web Services, engineered to scale and to stay available.

Hosting
Amazon Web Services (AWS), primary region eu-west-1 (Ireland). Fully cloud-based — no customer-deployed software required.
Architecture
Containerized microservices on AWS ECS with blue/green deployments and auto-scaling; CloudFront and S3 for delivery and storage.
Database
MongoDB Atlas replica set across multiple nodes, with compute and storage auto-scaling and cross-region backup snapshots.
Tenant isolation
Logical isolation per customer using a unique tenant identifier and row-level security.
Availability target
Engineered for 99.9% uptime. Real-time status is published at status.smartfoodsafe.com.
Backups
Automated daily backups, encrypted in transit and at rest, with quarterly restoration testing.
Disaster recovery
Documented, tested DR runbook with cross-region failover. Most recent test recovered all mission-critical modules within target.
Monitoring
Continuous monitoring via AWS CloudWatch, Datadog, and Grafana, with real-time alerting and full audit logging.
